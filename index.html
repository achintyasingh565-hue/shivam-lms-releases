Backup & Restore

Your loan records are stored inside this browser. To keep them safe — and to move them between computers — download a backup file regularly.

⤓ Download Backup

Saves all your loan records as a single file. Keep it somewhere safe (pen drive, email, cloud).

⤒ Restore Backup

Load records from a previously downloaded .json backup file. This replaces current data.

⚠ Uploaded document scans (Aadhaar, PAN, photographs, signed agreements) are stored on this device only — they are not inside the record backup above and are not synced to the cloud. Back them up separately below.

⤓ Back up documents

Saves every uploaded scan & photograph as one file. Keep it with your record backup.

⤒ Restore documents

Load scans from a previously downloaded documents file. Existing documents are kept; duplicates are skipped.

Team Members

Add staff accounts so colleagues can sign in with their own username and password on this computer.

Recovery Password Not set

Choose a second password only you know. If you ever forget your login password, type this at the sign-in screen to get back in and set a new one. Nothing is deleted — your records, staff accounts and settings stay exactly as they are. It is stored scrambled on this Mac, so nobody can read it out of the app.

Or generate a one-time code

Generate a one-time recovery code. If the Administrator password is ever forgotten, this code resets it from the sign-in screen — no data loss. Each code can be used once; generate a new one after use.

Central user list (all devices)

Publish this user list as the master copy. Every signed-in device then adopts these accounts and roles on its next sync, so a person has the same role everywhere. It updates roles and adds missing users — it never deletes an account or changes a password, so no one gets locked out. Publish from the owner-administrator's computer.

Auto-lock when idle

If the app is left open and untouched, it locks itself and asks for the password again. Set 0 to turn off.

minutes

For the strongest protection, also turn on FileVault (System Settings → Privacy & Security → FileVault) to encrypt your entire Mac. If you forget this password, clear it via your browser/app data — your records stay safe behind your Mac login.

Data protection — Aadhaar / PAN Off

Encrypts the ID number fields (Aadhaar / PAN) before they are stored in the cloud — an extra layer on top of the database's access control. Use the SAME passphrase on both devices; if they differ, the other device cannot read the IDs. Keep it safe: if the passphrase is lost, those ID fields can't be decrypted (the rest of each record is unaffected).

Install as an App

💻 On a Computer (Chrome / Edge)

  1. Open the browser menu (⋮ top-right).
  2. Choose "Install page as app" (Edge) or "Cast, save and share → Create shortcut…" (Chrome), then tick "Open as window".
  3. An icon is added to your desktop / taskbar — open it anytime like normal software.

📱 On a Phone (Android / iPhone)

  1. Open this page in Chrome (Android) or Safari (iPhone).
  2. Tap the menu / share button.
  3. Choose "Add to Home screen" — it appears as an app icon.

This app works fully offline and stores data on the device. Remember to use Backup & Restore to keep a safe copy of your records.
